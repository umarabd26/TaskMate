# TaskMate

TaskMate adalah aplikasi Android sederhana untuk membantu mahasiswa mencatat dan mengatur tugas kuliah.

## Fitur Aplikasi

* Menambah tugas
* Mengedit tugas
* Menghapus tugas
* Menandai tugas selesai
* Pengingat notifikasi tugas
* Pemilihan tanggal dan jam otomatis
* Penyimpanan data permanen
* Splash screen

## Teknologi yang Digunakan

* Kotlin
* Android Studio
* RecyclerView
* SharedPreferences
* AlarmManager
* Notification

## Cara Instalasi

1. Download file APK
2. Install di perangkat Android
3. Izinkan notifikasi jika diminta
4. Jalankan aplikasi

## Cara Penggunaan

1. Tekan tombol tambah tugas
2. Isi nama tugas dan mata kuliah
3. Pilih deadline
4. Pilih tanggal dan jam pengingat
5. Tekan tombol simpan
6. Tugas akan muncul di halaman utama
